# 公共标识多语言校对台

用于公共空间标识译文录入、术语校验、版面风险预览和紧急修订的本地优先工作台。示例包含轨道交通、商场、公园和医院标识。

## 功能

- 录入中文原文、目标语言、适用场景和法规/规范提示。
- 版面规格按场景管理：每个场景记录可用宽度档、字号上下限和最多行数（站台、疏散通道、公园等分别配置）；标识按所属场景套用规格，预览只能在该场景的宽度档与字号范围内调整。
- 实时预览换行、截断和溢出风险，统计预计行数、字符数和未命中的必选术语，给出高风险、需留意、版面安全三级判断；行数容量按场景的“最多行数”计算。
- 修改场景规格后，套用该规格的标识全部按新规格重算；原来不判高风险、按新规格溢出的标识自动判为高风险，并在场景页集中列出，其中已确认标识会退回待确认。
- 场景页可新增、编辑、删除场景规格；仍被标识引用的场景不允许删除。
- 每条标识记住自己的校对宽度档与字号，随项目保存在浏览器本地。
- 为每条译文绑定固定术语；术语与译文不一致时高亮告警，可逐条确认或删除。
- 支持草稿、待确认、需修改、已确认四种审校状态。
- 添加审校意见、回复并标记解决状态。
- 保存最多 12 个版本快照，按词/字符比较旧版与当前译文，绿色表示新增、红色表示删除。
- 生成只读预览链接；链接读取当前浏览器保存的本地版本，不提供服务端数据。
- 紧急修订模式会把已确认标识重置为待审校，强制重新确认；修订后可通过状态按钮回到审校流程。
- 多步撤销/重做、本地自动保存、断网继续编辑。
- 键盘操作：`J`/`K` 切换标识，`[`/`]` 在所属场景宽度档间切换，`-`/`=` 在场景字号范围内调整字号。

## 版面规格数据

- 场景规格（`scenarios`）和标识的场景引用（`scenarioId`）、当前宽度档/字号（`layoutWidth`、`layoutFont`）与项目一起存于浏览器 `localStorage`（键 `sologsb-1008-project-v2`，schema 2）。
- 升级前的 schema 1 数据（写死宽度档、`scenario` 为文本）在首次打开时自动迁移：按场景名归并到内置场景规格，未命中的场景名会以默认宽度档补建为独立规格。

## 技术栈

- Qwik 1 + Qwik City + TypeScript
- DaisyUI 5 + Tailwind CSS 4
- Qwik City 静态适配器
- 浏览器 `localStorage`
- nginx 静态部署

## 开发

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/`，由 Qwik City static adapter 生成可静态部署文件。

## Docker

容器内 nginx 监听 `80`，宿主端口按根端口表映射为 `10008`。

```bash
docker build -t sologsb-1008 .
docker run --rm -p 10008:80 sologsb-1008
```

访问 `http://localhost:10008`。

## 数据说明

项目和版本数据保存在当前浏览器 `localStorage`。只读预览链接仅对保存过同一浏览器本地数据的设备有效，不回传或公开业务数据。
